## Added

- Host and home: `casulo doctor` checks git and the container runtime, `casulo setup` creates `~/.casulo` and fixes what is missing, `casulo config` edits the global or a project's `casulo.toml`, and `casulo home` prints where casulo keeps its files.
- Projects: `casulo new <url>` clones a repository; `casulo new <dir>` uses a local directory in place, runs `git init` when it has no repository, warns about gaps in its git setup and masks `.git/hooks`. `[image]` install steps add a project's tools, and `casulo build` generates a Dockerfile and an image per project and agent.
- Running agents: `casulo run` starts the agent in a hardened container with the project's masks, and `--dry-run` prints the exact command; `casulo shell` opens a shell in the same container. Built-in manifests for Claude Code and Codex, your own in `~/.casulo/harnesses`, and `casulo harness list`. The login is kept per project, and the session and subagent models and effort are set per harness.
- Your agent setup: instructions, skills, subagents, MCP servers and workflows in `~/.casulo/agent`, given to every agent in its own format; `casulo add|edit|list|delete` manage them, checked as you save; ready-made examples to copy.
- Git and push: the `[git]` identity for the agent's commits; push over HTTPS, with git sending the token only to the project's host; a `pre-push` hook that refuses pushes to `protected_branches`, which stops mistakes, so protect those branches on the server too.
- Compose services: `casulo compose check` validates the compose file with an allowlist; every change needs your approval; `casulo run` starts the approved services and joins their network; `casulo compose up|down|ps`.
- Memory: a code graph with the links of Rust code; notes from agents and from you (file notes, project and branch notes, `promote`, conflicts settled in the editor); search with stemming that ranks linked files higher; the MCP server with five tools; `casulo run` starts it in its own container; session hooks with `overview`, for Claude Code only; `casulo describe|index|search|list|edit|promote|stop memory`.
